## Selected Projects

**[NYC Yellow Taxi Analytics](https://github.com/JasonHonghzj/nyc-yellow-taxi-analytics)**  
Where do New Yorkers catch yellow cabs, and how do fares change throughout the day? A PySpark pipeline validates monthly trip records and loads them into PostgreSQL. A six-page dashboard lets readers compare pickup zones, hours, and fares, then trace each month’s totals back to its source file.  
<sub>PySpark · PostgreSQL · Streamlit · Parquet</sub>

**[Research Bridge](https://github.com/JasonHonghzj/ResearchBrdige_2026Hackachusettes)**  
This team project maps early-detection research across 80,025 PubMed records. I built the data and retrieval engine for its separate 60-paper library. Readers can search by topic, compare papers side by side, and export a brief with links to the source material.  
<sub>Python · SQLite · scikit-learn · TF-IDF · LSA</sub>

**[Beyond ETFs](https://github.com/JasonHonghzj/Beyond-ETF-Portfolio-Optimization)**  
How did three ways of weighting the same six Taiwanese stocks compare with 10 local ETFs? I evaluated the historical portfolios by return, volatility, and Sharpe ratio. From January through November 2023, each portfolio earned a higher price return than seven of the ten benchmarks.  
<sub>R · Python · XGBoost · PyTorch · Black–Litterman</sub>

**[Transformer Arithmetic Reasoning](https://github.com/JasonHonghzj/transformer-math-reasoning)**  
I trained a small causal Transformer from scratch to add numbers inside nested parentheses, one token at a time. On a synthetic benchmark with ten settings and 1,000 examples per setting, it reproduced every intermediate step and final answer exactly. The repository includes the weights and a script for running the model on a CPU.  
<sub>Python · PyTorch · Causal attention · Curriculum learning</sub>

**[Stroke Risk Prediction](https://github.com/JasonHonghzj/Health_Prediction_Midterm_Challenge)**  
I compared five classifiers on a course dataset of 14,976 health records. On the same held-out split, logistic regression and a neural network produced nearly identical ROC AUC scores (0.8853 and 0.8854). I also used clustering to explore which symptom patterns tended to appear together.  
<sub>Python · pandas · scikit-learn · K-means · PCA</sub>

**[Butterfly Species Classification](https://github.com/JasonHonghzj/butterfly-species-classification)**  
I trained a convolutional neural network on iNaturalist photos to distinguish nine common butterfly species, grouping the remaining species into an “Other” class. The best checkpoint reached 79.22% validation accuracy. The inference pipeline exports probabilities for all ten classes on each unseen image.  
<sub>Python · PyTorch · CNNs · Data augmentation · Mixed-precision training</sub>
